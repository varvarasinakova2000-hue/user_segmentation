# Сегментация пользователей EdTech-платформы

Поведенческая сегментация учителей по логам активности на EdTech-платформе. Результаты нужны, чтобы персонализировать личный кабинет, настроить таргетированные коммуникации и повысить ключевые продуктовые метрики: MAU, число активных дней в месяц и удержание.

**Данные:** лог активности 1 500 учителей за 45 дней (01.03–14.04.2026): домашние задания, библиотека материалов, вебинары, оценки, расписание. 215 тыс. событий, из них 44% — активность ботов.

## Главный результат

Выделено **5 устойчивых сегментов**:

| Сегмент | Учителей | Активных дней в месяц | Главный модуль | Роль платформы |
|---|---|---|---|---|
| Ежедневные с ДЗ | 449 (30%) | 23 | домашние задания и оценки | основной рабочий инструмент; 69% всех действий |
| Библиотека | 539 (36%) | 12 | библиотека материалов | подготовка к очным урокам |
| Вебинары | 216 (14%) | 8 | вебинары | онлайн-занятия |
| Редко заходящие | 279 (19%) | 5 | нет «своего» модуля | эпизодический инструмент, главный риск оттока |
| Спящие | 17 (1%) | 2 | — | платформой фактически не пользуются |

Для каждого сегмента подготовлены рекомендации по личному кабинету, коммуникациям и сценариям взаимодействия. Первые приоритеты — реактивация «Редко заходящих» и рост частоты визитов в «Библиотеке».

## Как устроено исследование

1. **EDA и очистка данных.** Удалены 15 ботов (круглосуточная активность, время с точностью до секунды, около 6 300 событий на аккаунт), 29 полных дубликатов и 50 почти-дублей; 7 102 пропуска в `module` восстановлены по типу события.
2. **Матрица «учитель — метрики».** 16 продуктовых метрик в 4 группах: частота, регулярность, структура использования модулей, глубина работы с модулями. После удаления дублей, логарифмирования и стандартизации в модель вошли 12 признаков.
3. **Кластеризация.** K-Means и DBSCAN (scikit-learn), сравнение разных параметров.
4. **Оценка качества.** Метод локтя и силуэтный коэффициент указывают на 3–4 кластера; выбрано k = 4 (силуэт 0,447) как самый интерпретируемый вариант. DBSCAN независимо находит те же три основных сегмента.
5. **Портреты сегментов и бизнес-рекомендации.**
6. **Дополнительно:**
   - дерево решений относит новых учителей к сегментам с точностью около 97% по 6 понятным правилам;
   - RFM-анализ независимо подтверждает сегментацию и выделяет 164 учителя под угрозой ухода;
   - интерактивный дашборд в Power BI.

```

│   ├── teacher_activity_logs.csv      # исходный лог активности

    ├── dim_teacher.csv                # учителя: сегмент, активные дни, давность визита, RFM-группа
```

## Как запустить

Нужен Python 3.10+ и библиотеки (проверено на Python 3.13, pandas 3.0, numpy 2.4, scikit-learn 1.9, matplotlib 3.10, seaborn 0.13, scipy 1.17):

```bash
pip install pandas numpy scikit-learn matplotlib seaborn scipy jupyter
```

Затем откройте `user_segmentation.ipynb` из корня репозитория и выполните все ячейки по порядку (Run All). Ноутбук читает `data/teacher_activity_logs.csv` и заново создаёт `data/teacher_segments.csv` и файлы в `power_bi/`. Все случайные процессы зафиксированы (`random_state=42`), поэтому результаты воспроизводятся.

Дашборд открывается в Power BI Desktop (`dashboard.pbix`); его копии в PDF можно посмотреть без Power BI.
